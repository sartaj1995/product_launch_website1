# Product Launch Landing Page (Template 1)

A pre-launch countdown landing page for a new flavour/variant of a fictional protein supplement line, built entirely with **[Claude Code](https://claude.com/claude-code)** — fully vibecoded from a single prompt.

🔗 **[View the prompt used to build this](prompt.txt)**

## About

This is a portfolio/demo project: a fictional brand ("XYZ Nutrition") launching a fictional product flavour ("Belgian Dark Chocolate"). No real brand names, logos, or product photography are used — the hero product visual is an original CSS/SVG illustration.

## Features

- Sticky header with mobile nav overlay
- Hero section with live countdown timer and email "notify me" capture (client-side validation, no backend)
- Auto-scrolling marquee strip of claim chips
- Feature/benefit grid
- Two-column brand story section
- Certifications/trust grid
- FAQ accordion
- Closing CTA + footer

## Tech Stack

Plain HTML, CSS, and JavaScript — no build step, no dependencies. Fully responsive and accessible (focus states, alt/aria labels, contrast-checked), with scroll-reveal animations that respect `prefers-reduced-motion`.

## Built With Claude Code

This entire site — structure, styling, copy, and interactions — was generated by [Claude Code](https://claude.com/claude-code) from the prompt in [`prompt.txt`](prompt.txt). No hand-written code.

## Running Locally

Just open `index.html` in a browser, or serve the folder with any static file server:

```bash
npx serve .
```
